## 一、前端单元测试（historyStore / localStorage）

### TC-M2-001  收藏新增 + 去重  · `P0`

- **步骤**：
  ```js
  const s = historyStore
  s.add({ text: '今天在海边看日落', emotion: '清新', style: '文艺' })
  s.add({ text: '今天在海边看日落', emotion: '清新', style: '文艺' }) // 重复
  ```
- **预期**：
  - 第 1 次 add 返回非空 item（带 id）
  - 第 2 次 add 返回 `null`（按 text 去重）
  - `list().length === 1`

### TC-M2-002  删除单条  · `P0`

- **步骤**：add 两条 → 取第 1 条的 id → `remove(id)`
- **预期**：`list().length === 1`，且剩余的是第 2 条

### TC-M2-003  清空  · `P0`

- **步骤**：add 若干 → `clear()`
- **预期**：`list().length === 0`；localStorage key `wenzhang_dazi_favorites` 值为 `"[]"`

### TC-M2-004  has 判断  · `P0`

- **步骤**：add("海边") → `has("海边") === true`；`has("不存在") === false`

### TC-M2-005  groupCounts 分组计数  · `P1`

- **步骤**：add 文艺 x2、治愈 x1
- **预期**：`groupCounts()` 返回 `{ 文艺: 2, 治愈: 1 }`

### TC-M2-006  空 text 拒绝写入  · `P1`

- **步骤**：`add({ text: '   ' })`
- **预期**：返回 `null`，列表长度不变

### TC-M2-007  1000+ 容量  · `P1`

- **步骤**：脚本循环 add 1200 条不同文案
- **预期**：
  - 无异常抛出
  - `list().length >= 1000`
  - localStorage 可读回（无 QuotaExceededError 崩溃）

### TC-M2-008  容量超限时自动裁剪最旧  · `P2`

- **步骤**：把 MAX 临时改为 10，add 12 条
- **预期**：`list().length <= 10`，保留的是最新的

### TC-M2-009  隐私：收藏不含图片 base64  · `P0`

- **步骤**：add 一条文案（不含图），检查 localStorage 原始字符串
- **预期**：值中**不含** `data:image`、`base64`、`人脸` 等字样，仅含 `text/emotion/style/id/createdAt`

## 三、浏览器 e2e（我的收藏页）

### TC-M2-201  空态展示与跳转  · `P0`

- **前置**：清空 localStorage 收藏
- **步骤**：进入 `#/favorites`
- **预期**：
  - 显示"还没有收藏，去生成页点亮星标吧"
  - 点击"去生成 →"跳回 `#/generate`

### TC-M2-202  生成页收藏 → 收藏页可见  · `P0`

- **步骤**：
  1. `#/generate` 生成 3 条
  2. 点击第 1 条的"收藏"
- **预期**：
  - 星标点亮为"已收藏"
  - 进入 `#/favorites`，列表出现该条文案，左侧分组"全部"计数 = 1

### TC-M2-203  收藏页复制  · `P0`

- **步骤**：收藏页点击某条的复制图标
- **预期**：
  - `navigator.clipboard.writeText` 参数 = 该条文案
  - Toast"已复制到剪贴板"

### TC-M2-204  收藏页删除单条  · `P0`

- **步骤**：收藏页点击某条删除图标
- **预期**：该条从列表消失；"全部"计数减少 1；生成页对应文案星标恢复未点亮

### TC-M2-205  清空收藏（带确认）  · `P0`

- **步骤**：收藏页点"清空收藏" → 弹窗点"确定"
- **预期**：列表清空，显示空态；localStorage 收藏为 `[]`
- **步骤**：再点"清空收藏" → 弹窗点"取消"
- **预期**：列表**不清空**

### TC-M2-206  分组筛选  · `P1`

- **前置**：收藏含文艺 x2、治愈 x1
- **步骤**：点击左侧"文艺"
- **预期**：右侧只显示 2 条文艺文案；点击"治愈"显示 1 条；点击"全部"显示 3 条

### TC-M2-207  分组空态  · `P1`

- **前置**：收藏仅有"文艺"
- **步骤**：点击左侧"治愈"（若不存在该分组则跳过）
- **预期**：显示"这个分组还没有收藏"

### TC-M2-208  分组计数实时刷新  · `P1`

- **步骤**：在生成页收藏一条"治愈"文案 → 回到收藏页

### TC-M2-209  移动端收藏页单栏布局  · `P1`

## 四、人设记忆（后端 upsert / recall）

### TC-M2-301  upsert 返回 ok + id  · `P0`

- **请求**：`POST /api/persona/upsert`
  ```json
  { "device_id":"d-1", "text":"海边日落很好看", "emotion":"清新", "tone":"文艺" }
  ```
- **预期**：HTTP 200，`{ "ok": true, "id": "d-1:..." }`

### TC-M2-302  upsert 空 text 拒绝  · `P1`

- **请求**：`{ "device_id":"d-1", "text":"" }`
- **预期**：HTTP 422（Pydantic 校验）

### TC-M2-303  recall 返回相似 Top-K  · `P0`

- **前置**：已 upsert ≥2 条该 device 文案
- **请求**：`POST /api/persona/recall`
  ```json
  { "device_id":"d-1", "text":"周末海边走走", "top_k":2 }
  ```
- **预期**：HTTP 200，`examples` 为数组、长度 ≤ 2，内容为已 upsert 的文案文本

### TC-M2-304  recall 无历史返回空数组  · `P0`

- **请求**：`{ "device_id":"d-none", "text":"测试", "top_k":3 }`
- **预期**：HTTP 200，`{ "examples": [] }`

### TC-M2-305  AC8 · 有历史后 generate 注入召回  · `P0`

- **前置**：device `d-1` 已有 upsert 历史
- **请求**：`POST /api/generate`（`device_id: "d-1"`）
- **预期**：
  - HTTP 200
  - `used_persona === true`
  - 响应仍含 3 条 `copies`

### TC-M2-306  无历史时 used_persona=false  · `P1`

- **请求**：generate（全新 device_id）
- **预期**：`used_persona === false`

### TC-M2-307  跨设备隔离  · `P1`

- **步骤**：device A upsert"海边"，device B upsert"火锅"
- **步骤**：A 发起 recall
- **预期**：A 的 examples 只含 A 的历史文案，不含 B 的

### TC-M2-308  隐私：向量库不含图片  · `P0`

- **步骤**：`upsert` 后检查 Chroma 持久化目录 `backend/data/chroma/`
- **预期**：collection 中 documents 全部是文案文本；**无** `data:image` / base64 / 人脸元数据

## 五、全链路集成

### TC-M2-401  完整回流闭环  · `P0`

1. 生成页生成 3 条
2. 收藏其中 1 条 → 触发 `POST /api/persona/upsert`
3. 后端日志/接口确认 upsert 成功（id 含 device_id）
4. 再次生成 → 响应 `used_persona=true`

- **步骤**：收藏 1 条 → 刷新页面 → 进入收藏页
- **预期**：收藏仍在（localStorage 持久化）

### TC-M2-403  清空收藏后生成页星标同步  · `P0`

- **步骤**：收藏 A、B 两条 → 收藏页清空 → 回到生成页重新生成含 A 文案的结果
- **预期**：A 文案的星标**未点亮**
