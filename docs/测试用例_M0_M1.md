## 一、M0 脚手架（工程可运行）

> 目标：跑通前后端工程，验证接口注册、CORS、SQLite/Chroma 初始化、设计 Token。

### TC-M0-001  FastAPI 启动正常  · `P0`

- **前置**：cd `backend` 安装依赖
- **步骤**：`uvicorn app:app --port 8000`
- **预期**：
  - 终端打印 `Uvicorn running on http://127.0.0.1:8000`
  - SQLite 文件 `backend/data/wenzhang.db` 自动创建
  - ChromaDB 目录 `backend/data/chroma/` 自动创建
  - 启动日志无 ERROR

### TC-M0-002  健康检查  · `P0`

- **步骤**：`curl http://localhost:8000/api/health`
- **预期**：
  - HTTP 200
  - `{"status":"ok","version":"0.1.0"}`

### TC-M0-003  8 色情绪映射接口  · `P1`

- **步骤**：`curl http://localhost:8000/api/emotions`
- **预期**：包含 `日常/治愈/幽默/文艺/带货/凡尔赛/清新/情感` 八个 key，对应 8 色 HEX

### TC-M0-004  模板列表接口（M3 占位）  · `P1`

- **步骤**：`curl http://localhost:8000/api/templates`
- **预期**：
  - HTTP 200
  - 返回数组长度 ≥ 8
  - 各类目（旅行/美食/节日/情感/带货）至少各有 1 条
- **步骤**：`curl "http://localhost:8000/api/templates?category=美食"`
- **预期**：仅返回 category=="美食" 的条目

### TC-M0-005  Vite 工程启动  · `P0`

- **步骤**：cd `frontend && npm run dev`
- **预期**：
  - `Local: http://localhost:5173/`
  - 自动代理 `/api/*` → 8000
  - 控制台无红色 error

### TC-M0-006  设计 Token 与设计文档完全一致  · `P1`

- **检查**：`frontend/src/assets/styles/tokens.css` 内变量名/值
- **预期**：
  - 主色 `--c-primary: #E8590C`
  - 主深 `--c-primary-dark: #C7480A`
  - 8 个 `--em-*` 情绪色 HEX 与设计文档 §2.2 完全一致
  - 圆角/间距/阴影/字体变量全部存在

### TC-M0-007  CORS 跨域  · `P0`

- **前置**：前端 5173、后端 8000 同时启动
- **步骤**：前端 devtools 控制台执行
  ```js
  fetch('http://localhost:8000/api/health', { method:'GET' })
  ```
- **预期**：成功返回 `{"status":"ok"...}`，无 CORS 报错

## 二、M1 识图生成（核心主链路）

> 覆盖 PRD 第 7 节 AC1~AC6、AC7、AC9、AC10 中"不留存"以外的接口能力。

### 2.1 后端接口用例（`/api/generate`）

#### TC-M1-001  AC1 · 合法图片+文字 → 5s 内返回 3 条不同风格  · `P0`

- **请求**：
  ```json
  POST /api/generate
  {
    "image_base64": "data:image/jpeg;base64,/9j/...",
    "text": "在海边拍的",
    "tones": ["文艺","治愈","日常"],
    "device_id": "device-test-001"
  }
  ```
- **预期**：
  - HTTP 200
  - `copies.length` ∈ [3, 5]
  - 每条包含 `style / emotion / text`，且 `text` 非空
  - 在测试机器上 P95 耗时 ≤ 5s

#### TC-M1-002  AC1 · 仅文字（无图）也能生成  · `P0`

- **请求**：`{"text":"今天吃了火锅","tones":["日常"],"device_id":"device-test-002"}`
- **预期**：HTTP 200，`copies` 长度 ≥ 3

#### TC-M1-003  AC1 · 仅图片（无文字）也能生成  · `P1`

- **请求**：`{"image_base64":"<1x1 jpeg>","device_id":"device-test-003"}`
- **预期**：HTTP 200，能得到 ≥ 3 条文案

#### TC-M1-004  AC2 · 非白名单格式 → INVALID_IMAGE  · `P0`

- **请求**：`image_base64 = "data:image/gif;base64,xxxxx"`
- **预期**：
  - HTTP 422
  - `detail.code = "INVALID_IMAGE"`
  - `detail.message = "仅支持 JPG/PNG/WEBP 图片"`

#### TC-M1-005  AC2 · 超过 10MB → INVALID_IMAGE  · `P0`

- **请求**：构造一段 > 10MB 的合法 base64 jpeg
- **预期**：HTTP 422，`detail.code = "INVALID_IMAGE"`，message 含 "10MB"

#### TC-M1-006  AC2 · base64 解码失败 → INVALID_IMAGE  · `P1`

- **请求**：`image_base64 = "data:image/jpeg;base64,@@@@@@"`
- **预期**：HTTP 422 或 400，`detail.code = "INVALID_IMAGE"`

#### TC-M1-007  AC3 · 文字+图片均为空 → EMPTY_INPUT  · `P0`

- **请求**：`{"text":"","tones":[],"device_id":"d-007"}`
- **预期**：HTTP 422，`detail.code = "EMPTY_INPUT"`，message = "请先上传图片或写一句话"

#### TC-M1-008  AC6 · 模拟模型超时 → MODEL_TIMEOUT  · `P0`

- **前置**：临时将 `call_qwen_vl` 用 `await asyncio.sleep(7)` 替换
- **请求**：调一次正常接口
- **预期**：
  - HTTP 504
  - `detail.code = "MODEL_TIMEOUT"`
  - `detail.message = "生成超时，请重试"`

#### TC-M1-009  AC5 · 后端下游异常 → 兜底走 mock 不白屏  · `P1`

- **前置**：把 Qwen 调用抛 `RuntimeError`
- **步骤**：发起正常请求
- **预期**：仍返回 200（mock 兜底文案），前端正常渲染卡片

#### TC-M1-010  限流 · 30s 内超过 6 次 → RATE_LIMIT  · `P1`

- **步骤**：同 `device_id` 连发 7 次
- **预期**：前 6 次 200，第 7 次 HTTP 429，`detail.code = "RATE_LIMIT"`

#### TC-M1-011  响应字段 shape 校验  · `P0`

- **步骤**：发起合法请求，断言 JSON 结构
- **预期**：
  ```json
  {
    "vibe": "<non-empty str>",
    "copies": [
      { "style": "文艺|幽默|带货|日常|治愈|凡尔赛",
        "emotion": "日常|治愈|幽默|文艺|带货|凡尔赛|清新|情感",
        "text": "<12~140 chars>" }
      ...
    ],
    "used_persona": true|false
  }
  ```

#### TC-M1-012  AC9 · template=travel 注入模板提示词  · `P2`

- **步骤**：两次请求，仅 `template` 字段不同（`travel` vs `null`）
- **预期**：两次返回的文案池出现与"旅行/海边/度假"语义相关的差异（mock 下用模板字段提示）—— 这种差异在 mock 模式下难以严格断言，留到集成测试中验证 LLM 真实输出

#### TC-M1-013  AC10 · 服务端不留盘原图  · `P0`

- **步骤**：发起带图请求 → 检查
  - `backend/data/` 目录下不应新增任何 *.jpg / *.png / *.webp
  - `chroma/` 内 collection **不含** 图像向量（仅 documents = 文案文本）
- **预期**：通过；磁盘体积在测试前后基本不变（差值 < 1KB）

#### TC-M1-014  Chroma 启动幂等  · `P1`

- **步骤**：连续重启后端 3 次
- **预期**：每次启动均 `ensure_chroma()` 成功，无 `Collection already exists` 报错

#### TC-M1-015  emotion 字段值必须收敛在 8 色内  · `P1`

- **步骤**：跑 20 次生成，收集所有返回 `copies[].emotion`
- **预期**：取值的集合 ⊆ {日常, 治愈, 幽默, 文艺, 带货, 凡尔赛, 清新, 情感}
