## 一、前置环境（一次性，约 10 分钟）

| 软件 | 要求 | 下载 | 安装要点 |
|---|---|---|---|
| **Python** | 3.11 或以上 | https://www.python.org/downloads/ | ✅ **必须勾勾选 "Add Python to PATH"** |
| **Node.js** | **22 LTS 或更新**（含 npm） | https://nodejs.org/ | ⚠️ **Node 20 在 Windows 上 npm install 有 race condition bug，必须装 22+** |

> 验证方法：打开 cmd / PowerShell 输入 `python -V` 和 `npm -v`，能显示版本号就算成功。

## 五、脚本会自动做什么

1. 检测 Python / npm 是否已装（已装则显示 `[OK]`）
2. 探测空闲端口（自动避开你电脑上其他项目占用的 8000 / 5173）
3. 启动**后端**服务（黑窗口标题：`backend-8000` 或类似）
4. **首次运行**会自动 `npm install` 装前端依赖（1–3 分钟，需要网络；国内网络会自动重试镜像源）
5. 启动**前端**服务（黑窗口标题：`frontend-5173` 或类似）
6. 等待前端可访问后**自动打开浏览器**到 `http://localhost:5174` 之类（端口动态，显示哪个就开哪个）
7. 弹出产品界面 → 完事 🎉

> 💡 **不需要任何 API Key**。未配置时自动走内置 mock 文案池（62 条 + 关键词联想），所有功能可完整体验。

## 六、正常使用流程（演示 5 大页面）

1. **生成页**：输入"今天去海边了" → 点"生成" → 看 3 条逐字出现 → 点"换一条"会**重新生成全新文案**（不会再撞回旧的或收藏过的）
2. **看图生文**：上传一张照片 → 点"生成" → AI 识图后创作文案
3. **模板广场**：切到"节日"分类 → 点"生日祝福"卡片的某条示例 → 自动预载到生成页
4. **AI 润色**：粘贴一段文字 → 依次点「更幽默」「更治愈」→ 看到风格差异
5. **收藏页**：把生成页喜欢的文案点"收藏" → 切到收藏页 → 看分组效果

## 八、常见问题排查

### Q1: 双击 start.bat 后窗口一闪就没了
A: 大概率是 `.bat` 文件换行符不对。**在项目文件夹里按住 Shift 右键 → 在此处打开 PowerShell → 输入 `start.bat` 回车**，窗口不会关，能看到具体报错文字。

### Q2: 卡在 `npm install ...` 失败
A: 三选一：
- 切**手机热点**重试
- 项目**移到不带中文/括号的路径**（见第三节）
- 检查 Node 版本 `node -v` 是否 ≥ 18

### Q3: 浏览器自动打开了，但不是我这个产品
A: 已经修好了。最新脚本会**自动探测空闲端口**（5173 被占就用 5174、5175…），浏览器打开的就是你这次跑的端口，不会再串到别人的项目。

### Q4: 端口被占用
A: 无需手动处理。脚本会自动找下一个空闲端口（后端 8000–8020，前端 5173–5199），并在最后打印实际打开的 URL。

### Q5: 提示"Python 不是内部或外部命令"
A: Python 没装，或安装时**没勾"Add Python to PATH"**。重新安装 Python，**务必勾选该选项**。

### Q6: 双击后黑窗口显示 `[ERROR] npm install failed`
A: 跟着窗口里打印的 3 条建议做（换网络 / 换路径 / 升 Node）。国内网络脚本已自动重试 npmmirror 镜像，但极个别情况仍可能失败。

### Q7: 双击 .bat 弹出"Windows Defender SmartScreen / 已保护你的电脑"
A: 这是 Windows 对**从网络下载的 .bat** 的正常安全提示（任何从 GitHub / ZIP 下载的脚本第一次运行都会弹）。**不是产品问题，也不是卡死**——必须手动点一下才能继续：
1. 点弹窗里的 **"更多信息"**（或"仍要运行"）
2. 再点 **"仍要运行"**

`start.bat` 和 `stop.bat` 第一次都会各弹一次（Windows 记住"该用户允许过发布者"后就不再弹）。

> ⚠️ 如果 SmartScreen 弹窗写着"**目前无法访问 SmartScreen**"（联网验证失败），同样点弹窗下方的 **"运行"** 按钮即可，不会卡住后续。

## 九、数据隔离（隐私）

- 你的收藏、人设记忆全部存在**你自己电脑**的 `backend/app/data/wenzhang.db`
- 该文件**不会被推送到 GitHub**（`.gitignore` 已排除）
- 别人 clone 你的代码，数据库是空的；你 clone 别人的，也是空的
- 所以你收藏的文案只属于你这台电脑，互不可见 ✅

## 十、需要 API Key 才能做什么？

| 场景 | 是否需要 Key |
|---|---|
| 体验完整功能（生成/润色/看图） | **不需要**（mock 模式） |
| 用**真实通义千问 AI**（更聪明的生成） | 需要 `DASHSCOPE_API_KEY` |
| 接入方法 | 在 `backend/.env` 创建一行 `DASHSCOPE_API_KEY=sk-xxx`，重启 start.bat 即可 |

> 测试/演示**完全无需 Key**。如果你想体验真实 AI，可去 https://dashscope.aliyun.com/ 申请（有免费额度）。

## 十一、停止后下次怎么再启动

直接双击 `start.bat` 即可。脚本会：
- 检测到 `node_modules` 已存在 → 跳过安装
- 探测端口、起服务、开浏览器
- 整个过程通常 5 秒内完成
