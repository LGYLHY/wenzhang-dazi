# 文案搭子 · 产品需求文档（PRD）

> 版本：MVP v1.0 ｜ 更新日期：2026-08-20 ｜ 项目代号：Wutang-mocha

## 1. 产品概述

### 1.1 一句话定位
输入一段心情文字或一张图片，AI 现场创作 **3 条不同风格** 的朋友圈文案；配套模板广场、AI 润色、收藏记忆，一条龙解决"发朋友圈不知道写什么"的痛点。

### 1.2 产品背景
朋友圈 / 小红书用户在发布内容时，常因"配图有了、文案卡壳"而放弃分享。市面通用 AI 写作工具门槛高、需要注册登录、产出千篇一律。本产品主打 **零门槛、即时出稿、风格可选、本地隐私**。

### 1.3 目标用户
- 普通社交分享用户（学生、上班族）
- 需要高频产出短文案的内容创作者
- 想表达但"词穷"的轻度用户

### 1.4 核心痛点 → 解决方案
| 痛点 | 解决方案 |
|---|---|
| 不知道写什么 | 输入文字/图片，3 秒出 3 条风格化文案 |
| 文案太单调 | 模板广场 5 类 40 模板 + AI 润色 5 种风格 |
| 嫌注册登录麻烦 | 打开网页即用，无需账号 |
| 担心隐私外泄 | 收藏数据存本地（localStorage），不上传 |
| 没有 API Key 跑不起来 | 内置 mock 演示模式，零配置可体验 |

## 2. 功能需求

### 2.1 五大页面
| 页面 | 路由 | 核心功能 |
|---|---|---|
| **生成** | `/generate` | 输入文字 **或** 上传图片 → AI 生成 3 条不同风格文案（打字机逐字效果）→ 复制 / 收藏 / 换一条（换一条会重新调 API 生成全新文案，自动避开当前文案，不会重复回已展示或收藏过的）；人设记忆自动参考历史偏好 |
| **收藏** | `/favorites` | 本地收藏（localStorage），按情绪分组，支持复制 / 删除 / 一键清空 |
| **广场** | `/square` | 5 类 40 个模板（旅行 / 美食 / 情感 / 节日 / 带货），每个模板 3 条示例可单独点选预载到生成页 |
| **润色** | `/polish` | 5 种风格 AI 改写：更文艺 / 更简短 / 加 emoji / 更幽默 / 更治愈 |
| **我的** | `/help` | 使用说明 / 隐私说明 / 常见问题 |

### 2.2 后端 API 清单
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 健康检查 |
| POST | `/generate` | 文字/图片生成文案（支持多模态看图） |
| GET | `/emotions` | 获取情绪分组标签 |
| POST | `/persona/upsert` | 写入人设记忆（用户偏好） |
| POST | `/persona/recall` | 召回人设记忆，供生成参考 |
| POST | `/polish` | 文案风格润色改写 |
| GET | `/templates` | 获取模板广场数据 |

### 2.3 关键技术特性
- **多模态生成**：上传图片由通义千问 `qwen-vl-plus` 识图后创作文案（区别于纯文字工具的核心亮点）。
- **人设记忆**：基于 ChromaDB 向量库记录用户历史偏好，生成时自动参考，越用越懂你。
- **打字机输出**：生成结果逐字流式呈现，提升体验感。
- **零配置演示模式**：未配置 API Key 时自动走内置 mock 文案池（62 条 + 关键词联想），功能闭环完整。
- **换一条不撞车**：`onSwap` 重新调用 `/api/generate` 并传 `swap_text` 参数，后端在 prompt 与 mock 选词阶段均主动规避该文案，确保换出结果与原文案、收藏文案均不重复。

## 3. 非功能需求

| 维度 | 要求 |
|---|---|
| **隐私** | 收藏数据仅存浏览器 localStorage，不上传服务器；API Key 存于本地 `.env`，不进仓库 |
| **跨平台** | 提供 `start.bat`（Windows）/ `start.sh`（macOS·Linux）一键启动 |
| **可运行性** | 无 Key 也能跑（mock 模式）；有 Key 走真实 AI |
| **性能** | 生成响应通常在数秒内返回 |
| **兼容性** | 现代浏览器（Chrome / Edge / Safari） |

## 4. 技术架构

| 层 | 技术选型 |
|---|---|
| 前端 | Vue 3 + Vite（SPA，vue-router 5 路由） |
| 后端 | FastAPI + Uvicorn（Python 异步框架） |
| AI 模型 | 通义千问 `qwen-vl-plus`（看图）/ `qwen-turbo`（润色） |
| 结构化存储 | SQLite（`wenzhang.db`，收藏/人设） |
| 向量存储 | ChromaDB（人设记忆召回） |
| 代理 | Vite 开发服务器将 `/api/*` 代理到后端；启动脚本动态探测空闲端口（后端 8000–8020、前端 5173–5199），vite 通过 `VITE_API_PORT` 环境变量自动指向动态后端端口，避免与他人项目冲突 |

### 4.1 目录结构
```
backend/           FastAPI 后端（app/routers、app/services、app/data）
frontend/          Vue3 前端（src/views 五个页面、src/api 接口封装）
docs/              部署指南 + 测试用例 + 本 PRD
start.bat/.sh      一键启动脚本（通用版，自动装依赖）
README.md          项目首页说明
```

## 5. 运行与部署

### 方式一：一键启动（推荐，零门槛）
- Windows：clone 后 **双击 `start.bat`**（首次自动 `npm install`）
- macOS / Linux：`./start.sh`
- 脚本自动定位 python/npm、动态探测空闲端口避免与本地其他项目冲突，并在前端就绪后自动打开浏览器到实际端口（不再是写死的 5173）

### 方式二：手动启动（README 详述）
分别安装前后端依赖并启动（`pip install -r requirements.txt` + `npm install`）。

### 方式三：公网部署（老师/同学远程体验）
参见 `docs/DEPLOYMENT.md`，可部署至 Vercel / Render 等平台，生成公开链接。

> 注：`防火墙放行.bat` **仅用于局域网分享**（让同一 WiFi 的手机/其他电脑访问你跑起来的站点），与推送 GitHub 无关；推送 GitHub 走 HTTPS 443，无需任何防火墙配置。

## 7. 隐私与安全说明

1. **API Key 安全**：`.env` 已被 `.gitignore` 排除，绝不进入 GitHub 仓库；公开仓库亦不会泄露 Key。
